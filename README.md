# Guild Tracker — GF2TableToolkit

Приложение для автоматического сбора данных из таблицы гильдии игры **Girls' Frontline 2** через OCR.

Делает скриншоты таблицы гильдии, распознаёт имена и очки игроков, сохраняет историю по дням в базе данных SQLite. Поддерживает экспорт в CSV и синхронизацию с Google Sheets.

---

## Требования

- **Windows 10 / 11**
- **Python 3.12 или новее** ([скачать](https://www.python.org/downloads/))
- Интернет-соединение для первоначальной установки

---

## Установка

### 1. Скачайте Python 3.12+

Перейдите на [python.org/downloads](https://www.python.org/downloads/) и установите Python.
Прямая ссылка на [Python 3.12](https://www.python.org/ftp/python/3.12.10/python-3.12.10-amd64.exe)

> При установке **обязательно** отметьте галочку **"Add Python to PATH"**

### 2. Клонируйте репозиторий

```
git clone https://github.com/Agress0r/GF2TableToolkit.git
cd GF2TableToolkit
```

Или скачайте ZIP-архив через кнопку **Code → Download ZIP** и распакуйте.

### 3. Запустите установщик

```
setup.bat
```

Установщик автоматически:
- Создаст виртуальное окружение `GF2TTK\`
- Установит все зависимости
- Прогреет OCR-модели (первый запуск будет быстрее)

### 4. Запустите приложение

```
scripts\run.bat
```

## Первый запуск

### 1. Создайте сезон
Нажмите кнопку **«Сезоны»** в боковой панели → **«Добавить сезон»**.

### 2. Загрузите скриншоты (ручной режим)
Нажмите **«Обработка данных»**:
- Сделайте скриншоты таблицы гильдии в игре, приложение поддерживает вставку из буффера обмена.
- Загрузите все скриншоты в приложение.
- Произведите калибровку смещений, пример того какие зоны нужно выделять в гифке ниже.
- - Это делается **один раз**, настройки сохраняются для последующих обработок. Вы можете перекалибровать зоны если возникают проблемы с распознованием имён или счёта. 
- Нажмите **«Обработать»** — приложение распознает бейджи, имена и очки автоматически.
- При первом добавлении игроков проверьте правильность ВСЕХ имён, поправьте неправильно распознанные имена OCR. **ЭТО ВАЖНО**!
- Выберите день и сохраните данные в базу данных.
### ВАЖНО! ###
- После первого распознования и добавления имён в **БД/Локальную таблицу**, при последующих обработках приложение будет автоматически распозновать имена и сравнивать их с уже имеющимися в таблице, и при высоком проценте совпадения имени будет автоматически добавлять результат к нужному игроку.

К примеру, игрок с ником Kolin был распознан как Koln, и так же отображён в данных после обработки. Вы редактируете его на верный вариант при добавлении **в первый раз**, и при последующих осечках OCR результаты Koln будет приравниваться к Kolin.

## Google Sheets (опционально)

Для синхронизации данных с Google Таблицей нужен Google Service Account.

### Настройка

1. Откройте [Google Cloud Console](https://console.cloud.google.com/)
2. Создайте новый проект (или используйте существующий)
3. Включите API: **Google Sheets API** и **Google Drive API**
4. В разделе **«Учётные данные»** создайте **Service Account**
5. Создайте ключ для сервисного аккаунта (тип: JSON), скачайте файл
6. Переименуйте файл в `credentials.json` и поместите в корень папки проекта
7. Поделитесь вашей Google Таблицей с email сервисного аккаунта (права редактора)
8. В настройках приложения укажите ID таблицы (из URL: `...spreadsheets/d/<ID>/...`)

> **Важно:** `credentials.json` содержит секретный ключ. Не передавайте его третьим лицам и не добавляйте в git.

### Структура таблицы

Приложение ожидает фиксированную структуру листа:
```
Строка 1:   заголовки (Дата | Дни 1–7 | Сезон | ...)
Строка 2:   "Всего очков" — итоговые суммы
Строки 3+:  игроки: Col A = имя, Col B–H = дни 1–7
```

## Структура проекта

```
GF2TableToolkit/
├── setup.bat                — установщик окружения
├── main.py                  — точка входа приложения
├── requirements.txt         — зависимости Python
├── GuildBossToolkit.ico     — иконка приложения
├── assets/
│   └── badges/              — шаблоны бейджей для распознавания рангов
├── config/
│   └── settings_manager.py  — загрузка/сохранение настроек
├── core/
│   ├── ocr.py               — OCR (RapidOCR + ddddocr)
│   ├── badge_detector.py    — детектор бейджей (cv2.matchTemplate)
│   ├── capture.py           — захват экрана (QThread)
│   └── sheets_sync.py       — синхронизация с Google Sheets
├── db/
│   └── database.py          — SQLite БД (сезоны, игроки, очки)
├── ui/                      — интерфейс PyQt6
├── scripts/
│   ├── run.bat              — запуск приложения
│   └── test.bat             — запуск тестов
└── debug_crops/             — отладочные кропы OCR (если включено в настройках)
```
