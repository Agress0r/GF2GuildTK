# Guild Tracker — GF2GuildTK

Учёт очков гильдии **Girls’ Frontline 2** по сезонам и дням. Приложение для Windows с локальной базой SQLite, импортом из игры, OCR и обменом с Google Таблицами.

**Версия: 1.0.0 · Windows 10/11 x64 · Portable EXE**

[Скачать выпуск](https://github.com/Agress0r/GF2GuildTK/releases/latest) · [История изменений](CHANGELOG.md) · [Сборка и выпуск](docs/releases.md)

## Быстрый запуск

1. Скачайте `GuildTracker-1.0.0-windows-x64.zip` из раздела **Releases** и распакуйте в отдельную папку с правом записи. Для следующих версий имя архива содержит новый номер выпуска.
2. Запустите `GuildTracker.exe`. Python и OCR-модели уже включены.
3. Создайте сезон, выберите способ импорта и проверьте день сезона перед сохранением.

Первый запуск создаёт рядом с EXE `settings.json` и `guild_tracker.db`. Ключ Google и драйвер Npcap нужны только для соответствующих способов импорта.

## Возможности

| Задача | Как работает |
|---|---|
| Учёт гильдии | Сезоны, семь дней, итоговые очки, поиск, сортировка и ручные исправления |
| Импорт из игры | Захват ответа через Npcap, предпросмотр, сопоставление игроков по UID |
| OCR | PNG/JPEG/WebP/BMP, перетаскивание и Ctrl+V, проверка имён/очков, восстановление черновика |
| Google Таблицы | Выбор и запоминание листа, импорт/экспорт, выбор значения для каждой спорной ячейки |
| CSV | Экспорт текущего сезона в UTF-8 с поддержкой кириллицы и китайских имён |
| Контроль изменений | Журнал, резервные копии и отмена последнего импорта |
| Интерфейс | Тёмная тема, высокий контраст, масштаб текста 100–160% |

### Захват из игры

Нажмите **«Импорт из захвата данных»**, затем откройте список участников гильдии в игре. При получении полного ответа откроется предпросмотр. Проверьте сезон, день и соответствия новых имён.

Если Npcap не установлен, приложение предложит скачать официальный установщик и запустить его. После установки выполните повторную проверку; при необходимости перезапустите приложение. [Подробная инструкция](docs/guild_live_capture.md).

### Обработка изображений

Сделайте снимки внешним способом, откройте **«Ручная обработка OCR»** и добавьте их файлами или через буфер обмена. В **«Калибровка OCR»** задайте зоны бейджа, имени и счёта; профиль зависит от разрешения снимка и масштаба интерфейса игры.

Проверьте результаты перед записью: OCR может ошибаться. Подтверждённый список сохраняется целиком; ошибка записи откатывает импорт.

### Google Таблицы

В настройках добавьте ID таблицы и путь к JSON-ключу сервисного аккаунта Google. В проекте Google должен быть включён Sheets API; для чтения списка видимых листов и метаданных используется доступ, разрешённый ключу. Предоставьте сервисному аккаунту доступ к нужной таблице, а для экспорта — право редактирования.

Ожидаемый формат листа:

| Строки / столбцы | Содержимое |
|---|---|
| Строка 1 | Заголовки |
| Строка 2 | Итоги |
| Строки 3 и далее | Игроки |
| A | Имя игрока |
| B–H | Приращения очков за дни 1–7 |
| I | Итог сезона; при экспорте приложение этот столбец не изменяет |

Локальная БД хранит **накопительные очки**, Google — **прибавки за день**. Приложение выполняет преобразование. Нули после последнего дня с ненулевыми очками считаются заготовкой шаблона и не импортируются. Экспорт обновляет сопоставленные строки; отсутствующих игроков нужно добавить в лист самостоятельно.

Перед импортом и экспортом выберите лист и проверьте предпросмотр. Если затронутые данные изменились после загрузки предпросмотра, обновите его и повторите операцию.

## Данные и обновление

Закройте приложение, сохраните копию своей папки с данными и замените **только `GuildTracker.exe`** новым файлом из Releases. База, настройки и ключ Google не поставляются в релизном архиве и не должны заменяться при обновлении. Автоматического обновления внутри приложения нет.

| Файл / папка | Назначение |
|---|---|
| `guild_tracker.db` | Основная база; можно выбрать другую в настройках |
| `settings.json` | Настройки portable-версии; при запуске исходников — `config/settings.json` |
| `backups/` | Последние резервные копии основной БД |
| `backups/<имя БД>/` | Отдельные копии дополнительных баз |
| `drafts/` | Незавершённая обработка OCR |
| `captures/live/` | Диагностические файлы захвата |
| `credentials.json` | Ваш ключ Google, если используется интеграция |

Отменить последний импорт можно, пока после него не внесены другие изменения. Перед отменой создаётся дополнительная копия. Не публикуйте свои базы, захваты и ключ Google.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+F | Поиск игрока |
| Ctrl+O | Ручная обработка OCR |
| Ctrl+I | Импорт Google |
| Ctrl+Shift+I | Сетевой захват |
| Ctrl+E | Экспорт Google |
| Ctrl+H | История |
| Ctrl+Z | Отмена последнего импорта |
| Ctrl+V | Вставка изображения в окне OCR или калибровки |

## Запуск из исходников

Нужен **Python 3.12 x64**. Установщик проверяет версию и создаёт окружение `GF2TTK/`.

```bat
setup.bat
run.bat
```

Для разработки и тестов:

```powershell
.\GF2TTK\Scripts\python.exe -m pip install -r requirements-dev.txt
.\GF2TTK\Scripts\python.exe -m pytest tests -q
```
