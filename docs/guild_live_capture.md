# Автоматический сбор очков клана

Выберите сезон и нажмите **«Импорт из захвата данных»**. Приложение начнёт
прослушивать игровой TCP-поток через установленный в Windows драйвер Npcap.
Откройте список участников клана в игре. Как только полный ответ будет получен,
окно ожидания закроется и откроется предпросмотр игроков и очков. Дополнительные
кнопки и запуск PowerShell для захвата не нужны.

Перед записью проверьте сезон, день (1–7) и сопоставление новых имён с игроками
базы. Приложение создаст резервную копию БД.

Если ответ не получен за три минуты, окно покажет, были ли пакеты игры и ответ
сервера. Можно повторить захват. Если игра использует кэш вкладки, перейдите
на другой экран и снова откройте список участников.

Для этого режима требуется установленный Npcap. Приложение слушает все доступные
сетевые адаптеры, включая VPN и виртуальные, и сохраняет только пакеты TCP/7001
в `captures/live/` для диагностики. Эта папка исключена из Git. Права
администратора обычно не требуются, если Npcap разрешает захват текущему
пользователю; при иной настройке драйвера приложение покажет ошибку доступа.

Если Npcap отсутствует, окно сетевого импорта предложит скачать и установить его.
После согласия приложение скачает актуальный установщик с `https://npcap.com`,
проверит цифровую подпись и запустит обычный мастер установки. Windows запросит
права администратора; завершите шаги мастера и нажмите **«Проверить после установки»**.
Если Npcap установлен, но ещё недоступен приложению, перезапустите Guild Tracker.
Если мастер требует перезагрузку Windows, выполните её. При ошибке загрузки можно
открыть официальный сайт кнопкой в том же окне и установить Npcap вручную.
От предложения можно отказаться: OCR и остальные функции приложения доступны
без этого драйвера. Установщик Npcap не включается в распространяемый EXE.

Декодируется игровой ответ `0x559d`. Если протокол игры изменится или сервер
не отправит список, БД останется без изменений.
