# Изменения Guild Tracker

## [1.0.0]

Первый оформленный portable-релиз для Windows x64.

### Возможности

- Учёт гильдии по сезонам и семи дням, поиск, сортировка и ручное редактирование.
- Автоматический захват списка гильдии через Npcap с сопоставлением по игровому UID.
- OCR готовых изображений и буфера обмена, калибровка по разрешению и масштабу, сохранение черновика.
- Импорт и экспорт Google Таблиц с выбором листа и предпросмотром каждой спорной ячейки; экспорт CSV.
- История изменений, резервные копии и отмена последнего импорта.
- Единое тёмное оформление, высокий контраст, масштаб текста и горячие клавиши.

### Исправления

- Новый путь БД не заменяется основной базой; копии разных БД изолированы.
- OCR-импорт записывается одной транзакцией и сохраняет проверенные имена.
- Буквы в распознанном числе не удаляются с потерей разрядов: используется второй OCR-движок.
- Импорт раннего дня сохраняет итог более поздних дней.
- Google-экспорт привязан к ID листа и проверяет изменения строки после предпросмотра.
- Исправлены импорт существующих игроков в новый сезон, форматы чисел и повторяющиеся имена.
- Исправлены обрезанные элементы интерфейса, стрелки числовых полей и обработка ошибки записи CSV.
- Устранён конфликт библиотек Microsoft C++ при загрузке OCR внутри portable EXE.

### Распространение

- Один EXE со встроенными Python и моделями OCR, ZIP и SHA-256.
- Версия в свойствах EXE, закреплённые зависимости сборки и проверка EXE в пустом каталоге.
- Подготовка выпуска одной командой; GitHub Actions создаёт черновик релиза по тегу версии.
- Npcap и ключ Google не включены. Пользовательские базы и настройки в релиз не входят.
